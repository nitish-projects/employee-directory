# Employee Directory

A responsive Employee Directory web application built with **Vite, JavaScript, HTML, and CSS**. The application fetches employee data from the Random User API and provides an interactive interface for searching, filtering, sorting, favoriting, and viewing employee details.

## ✨ Features

* 👥 Display employee information dynamically from an API
* 🔍 Search employees by first or last name
* 🏢 Filter employees by department
* ⭐ Add and remove employees from favorites
* 💾 Store favorites using browser `localStorage`
* 📋 View detailed employee information in a modal
* 🔤 Sort employees from A–Z and Z–A
* ⭐ Filter and display favorite employees only
* 🌙 Dark mode with saved theme preference
* 📱 Responsive user interface
* ⚡ API error handling

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/nitish-projects/employee-directory.git
```

Open the project:

```bash
cd employee-directory
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
